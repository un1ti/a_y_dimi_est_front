# Scientific Arbitrator — Frontend

Веб-интерфейс для анализа и сравнения научных публикаций с использованием искусственного интеллекта.

## Возможности

- Загрузка научных статей в формате PDF.
- Просмотр загруженных публикаций.
- Запуск анализа и сравнения исследований.
- Отображение извлечённых метрик, результатов и выводов.
- Просмотр доказательств со ссылками на исходные документы.
- Экспорт результатов анализа.

## Технологии

- JavaScript
- Node.js
- REST API для взаимодействия с Backend

## Как работает

1. Пользователь загружает PDF через интерфейс.
2. Frontend отправляет документ на Backend.
3. Backend обрабатывает публикацию и возвращает результаты.
4. Интерфейс отображает извлечённые данные, сравнения и ссылки на источники.

## Запуск

Установите Node.js и зависимости проекта:

```bash
npm install
```

Запустите приложение:

```bash
npm run dev
```

Убедитесь, что Backend запущен и адрес API правильно указан в настройках Frontend.

## Назначение

Frontend отвечает за взаимодействие с пользователем и визуализацию результатов. Обработка научных данных и работа с нейросетью выполняются на Backend.
