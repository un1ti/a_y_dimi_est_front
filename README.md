# RAG Research Analyzer

RAG Research Analyzer помогает исследователям сравнивать научные публикации о RAG (Retrieval-Augmented Generation) — системах, в которых языковая модель строит ответ с опорой на найденные документы. Цель проекта — собрать результаты экспериментов из разных статей в одной библиотеке и дать читателю возможность проверить каждое найденное значение по первоисточнику.

## От статьи к карточке эксперимента

Пользователь добавляет в библиотеку PDF с текстовым слоем. По запросу на анализ сайт передаёт документ локальному ядру Scientific Arbitrator v2.5. Ядро ищет результаты в таблицах и тексте статьи. Среди параметров, которые оно умеет извлекать, — метод поиска, число отобранных фрагментов, их размер и перекрытие, названия моделей и значения метрик.

В карточке публикации результаты сгруппированы по экспериментам. Для каждой метрики сохраняются исходное значение, единица измерения и известные условия оценки. Если ядро нашло подтверждающий фрагмент, рядом с результатом появляется ссылка на страницу PDF. Читатель может открыть её и увидеть, к какой строке таблицы или фразе относится число. Проверка карточки отмечает пропуски в описании эксперимента и значения за границами шкалы метрики.

## Сравнение исследований

В каталоге можно отобрать эксперименты по задаче, набору данных или метрике и поставить их результаты рядом. Например, две статьи могут приводить Recall@5 — долю релевантных документов, найденных среди первых пяти результатов поиска. Таблица показывает, на каких данных и по какому протоколу получено каждое значение, и отмечает различия в условиях оценки.

Публикации можно объединять в тематические коллекции. Для обзора литературы карточку вместе с цитатами и результатами проверки можно сохранить в JSON, а отдельные измерения — выгрузить в CSV.

## Где хранятся данные

Анализ выполняется на компьютере, где работает сайт. Сервер Node.js передаёт PDF ядру на Python и сохраняет результаты в SQLite. Оригиналы PDF хранятся рядом с базой. При следующем открытии библиотеки карточки, коллекции и ссылки на страницы доступны без повторного анализа статей.
